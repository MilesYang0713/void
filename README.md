# VOID v0.19.0 — Personal Alpha

本版本固定手机端核心逻辑，并将后续路线切换为“私人长期使用 → 根据真实习惯迭代”。

## 手机底部导航

```text
主题 ｜ 速记 ｜ 灵感箱 ｜ 设置
```

独立“构思”页面已经取消。

## 速记与结构化新增的区别

- **速记**：只有一个大输入框，不需要先想标题、颜色和归属；保存后自动进入灵感箱。
- **主题中的 `＋`**：给当前主体或当前分支添加结构化子分支。
- **灵感箱**：把未整理速记转为主体，或归入任意已有主题和分支。

## 灵感箱整理

每条内容支持：

- 整理归入指定主题或分支
- 转为独立主体
- 放回原位（仅适用于从结构中暂存的内容）
- 删除到黑洞，保留 14 天
- 展开并查看完整主题结构

## 私人远程使用

本版本不需要云端部署前端。推荐：

```powershell
npm run build
npm run preview:private
```

另开 PowerShell：

```powershell
tailscale serve --bg 4173
```

详细步骤见 [PRIVATE_ACCESS.md](./PRIVATE_ACCESS.md)。

不要运行 `tailscale funnel`。

## 普通开发

```powershell
npm run dev
```

电脑强制查看手机版：

```text
http://localhost:5173/?mobile=1
```
